## 1. Інструкція запуску
1. Клонувати репозиторій: `git clone <посилання_на_ваш_репозиторій>`
2. Перейти в папку проєкту: `cd lab2`
3. Встановити залежності: `npm install --legacy-peer-deps`
4. Запустити проєкт: `npx expo start -c`
5. Відсканувати QR-код через додаток Expo Go на смартфоні або натиснути `a` для запуску на Android-емуляторі.

## 2. Опис реалізованого функціоналу
* **Вкладена навігація:** Реалізовано `Drawer Navigator` як головне меню, всередині якого працює `Stack Navigator` для переходу між списком новин та їх деталями.
* **Кастомне меню:** Створено компонент `CustomDrawer` з відображенням фотографії, ПІБ та групи користувача.
* **Стрічка новин (FlatList):** Оптимізований список із налаштуваннями віртуалізації (`initialNumToRender`, `windowSize` тощо). Реалізовано імітацію завантаження даних за допомогою pull-to-refresh (`onRefresh`) та infinite scroll (`onEndReached`).
* **Список контактів (SectionList):** Реалізовано відображення згрупованих за алфавітом контактів із закріпленням заголовків секцій під час скролінгу (`stickySectionHeadersEnabled`).

## 4. Висновки

Під час виконання лабораторної роботи було здобуто та закріплено практичні навички побудови складної маршрутизації та оптимізованого відображення великих масивів даних у React Native.

У результаті розробки застосунку було реалізовано:
1. **Вкладену навігацію (Nested Navigation):** Налаштовано ефективну комбінацію `Drawer Navigator` (для глобального бокового меню) та `Stack Navigator` (для переходів "вглиб" між списком новин та екраном деталей). Створено кастомний компонент меню (`CustomDrawer`), а також опановано механізм передачі параметрів між екранами через об'єкт `route`.
2. **Оптимізовані списки даних (FlatList):** Застосовано компонент `FlatList` для відображення стрічки новин. Завдяки механізму віртуалізації досягнуто високої продуктивності при рендерингу великої кількості елементів. Реалізовано сучасні UX-патерни: оновлення свайпом вниз (`pull-to-refresh`) та підвантаження нових даних при досягненні кінця списку (`infinite scroll`).
3. **Ієрархічні структури (SectionList):** Використано `SectionList` для виведення списку контактів, логічно згрупованих за алфавітом. Налаштовано візуальне закріплення заголовків секцій (`sticky headers`) під час прокручування, що значно покращує орієнтацію користувача в масиві даних.
